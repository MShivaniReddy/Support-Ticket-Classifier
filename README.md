# 🤖 AI Support Ticket Classifier

An intelligent Machine Learning application that automatically classifies customer support tickets into different categories and predicts their urgency level.

The project uses **TF-IDF**, **Logistic Regression**, and **Streamlit** to provide real-time ticket classification through a simple web interface.

---

## 🚀 Features

- 📝 Enter customer support tickets
- 🤖 Automatically classify the ticket category
- ⚡ Predict ticket urgency
- 📊 Real-time predictions
- 🎨 Interactive Streamlit dashboard
- 🧠 Machine Learning-based text classification
- 📱 Simple and user-friendly interface

---

## 🏷️ Ticket Categories

The system can classify tickets into categories such as:

- Technical Issue
- Billing
- Product Support
- Refund Request
- Account Issue

---

## ⚡ Urgency Levels

The system predicts:

- 🟢 Low
- 🟡 Medium
- 🔴 High
